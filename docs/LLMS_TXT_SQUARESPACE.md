## What Squarespace / llms.txt expects

- **Format:** Markdown. Spec ([llmstxt.org](https://llmstxt.org/)): required `# Site name`, optional `>` summary, short notes, then `##` sections with curated links (`- [Name](url): one-line note`).
- **Length:** Keep concise and factual. Squarespace often flags files as most effective under ~2,000 characters; the open spec has no hard cap.
- **Best practice:** Curate what AI should cite—product truth, company name, key URLs—not a full sitemap dump. Prefer honest scope over marketing superlatives.
- **Do not** claim features that are out of the current S-PUL build (Central Intelligence, voice, RAG).

## How to Save in Squarespace

1. Open the site that hosts **webpointllc.com** / **taxcert.ai** (marketing).
2. Go to **SEO / AI Visibility** → **SEO Settings** → **LLMS.txt** (or **Search appearance → LLMS.txt**).
3. Enable the feature if there is a toggle.
4. Replace the draft box with the **Paste-ready body** below (entire block).
5. Click **Save** (top right). Do not leave typos from the old meta description.
6. Verify in a private window: `https://webpointllc.com/llms.txt` (and `https://taxcert.ai/llms.txt` if that domain shares the same site).

Optional later: align the site **meta description** with the same wording so OG/Twitter tags stop shipping the typo draft.
