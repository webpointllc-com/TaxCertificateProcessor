Source disk · not mounted here

WD Passport clone

This cloud VM has no USB and no self-hosted Mac worker. Blinking green means power, not “Finder can see it.” Follow the steps below on the Mac the drive is plugged into.

  1. Disk Utility → View → Show All Devices. Look for Western Digital / Passport. If it is listed but grey: click it → Mount.
  2. If format is NTFS or exFAT and Mount fails: System Settings → Privacy & Security → Files and Folders / Full Disk Access — enable Terminal, Disk Utility, and Cursor. Then “Allow” any External Volumes prompt.
  3. NTFS often needs macFUSE + Mounty (or Microsoft NTFS). Powered + unsupported FS = blinking green, empty Finder.
  4. Finder → Go → Computer (⇧⌘C). Also Go → Go to Folder → /Volumes.
  5. Once mounted, find the workplace-technologies clone. In Terminal: export WORKPLACE_CLONE_PATH="/Volumes/…/clone" then npm run import:workplace.
